This is a Snake and Ladders game for an unlimited number of players, here are some ground rules for running the game:
  1. simply run the code in the terminal and the game will start
  2. you must have at least 2 players or you will not be able to play
  3. you can make a player name anything as long as there are no duplicate names
  4. while playing, you can enter any input/just press enter to roll or type "Quit" to exit to the menu while the game is active
  5. you can replay the game or view match history from the menu after a game has concluded
  6. once you exit (type 4 in the endgame menu), the code will stop running, you can start the program again by running it in a new terminal
     
Thank you for reading, and have fun playing Snakes and Ladders
